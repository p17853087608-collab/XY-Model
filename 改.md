很好，这一步其实很关键——**很多 reviewer 会先看 GitHub README，再决定你 reproducibility 做得怎么样**。你现在论文的 Data availability 已经没问题了，README 要做到三件事：

> 1️⃣ 让人一看就知道“可以复现”
> 2️⃣ 解释“为什么没有完整数据”
> 3️⃣ 教别人“怎么从 0 跑到图”

我给你一个**可以直接用的 README 模板（已针对你项目定制）**👇

---

## ✅ README.md 推荐结构（直接复制改就行）

````markdown
# XY Model – Monte Carlo + Machine Learning

This repository contains the code and data necessary to reproduce the results of our study on the XY model using Monte Carlo simulations and machine learning.

---

## 📦 Repository Contents

- `data_generation/` – Monte Carlo simulation scripts  
- `training/` – Model training scripts  
- `analysis/` – Bootstrap analysis and finite-size scaling (FSS)  
- `plotting/` – Scripts to generate figures  
- `example_data/` – Representative example datasets  
- `processed_data/` – Data used to generate the main figures  
- `models/` – Trained model weights  

---

## 📊 Data Availability

Due to their large size (tens of GB), the full raw Monte Carlo simulation datasets are **not included** in this repository.

To ensure reproducibility, we provide:
- All scripts required to generate the data
- Representative example datasets (see `example_data/`)
- Processed data used in the main figures (see `processed_data/`)
- Trained model weights (see `models/`)

The example datasets are intended to illustrate the data format and usage.  
The full datasets can be regenerated using the provided scripts.

If needed, the complete raw datasets are available from the authors upon reasonable request.

---

## 🚀 Reproducibility Guide

### 1. Generate Monte Carlo data
```bash
python data_generation/run_simulation.py
````

### 2. Train the model

```bash
python training/train_model.py
```

### 3. Perform bootstrap analysis

```bash
python analysis/bootstrap.py
```

### 4. Finite-size scaling (FSS)

```bash
python analysis/fss_fit.py
```

### 5. Generate figures

```bash
python plotting/plot_results.py
```

---

## 🧪 Quick Start (using example data)

If you do not want to regenerate the full dataset:

```bash
python plotting/plot_results.py --input example_data/
```

---

## 🧾 Data Format

The example datasets in `example_data/` demonstrate the structure of the simulation outputs.
Each dataset includes:

* Configuration data
* Observables
* Labels (if applicable)

Refer to comments in the scripts for detailed format descriptions.

---

## 📌 Notes

* Running full simulations may require significant computational time and storage.
* Results in the paper were obtained using large-scale datasets (tens of GB).

---

## 🔗 Repository

[https://github.com/p17853087608-collab/XY-Model](https://github.com/p17853087608-collab/XY-Model)

````

## 🔥 关键设计点（你一定要理解）

### 1️⃣ 明确区分三种数据（非常重要）

README 里你已经清楚区分了：

| 类型 | 是否提供 | 用途 |
|------|--------|------|
| example_data | ✅ | 教别人怎么用 |
| processed_data | ✅ | 直接复现论文图 |
| raw simulation data | ❌ | 太大 |

👉 reviewer 看到这个结构会非常放心

---

### 2️⃣ 一句关键话（核心防御）

> **"The full datasets can be regenerated using the provided scripts."**

这是你整个 reproducibility 的核心逻辑。

---

### 3️⃣ Quick Start 是加分项

很多人忽略这一点，但 reviewer 很喜欢：

```bash
python plotting/plot_results.py --input example_data/
````

👉 说明：

* 不用跑 Monte Carlo 也能看到结果
* 代码是可运行的

---

### 4️⃣ models/（权重）一定要写出来

你已经放了 trained weights，这其实是**加分项**：

👉 reviewer 会觉得你：

* 不只是“能复现”
* 还“降低复现成本”

---

## ⚠️ 你 README 里绝对不要写的坑

避免这些：

* ❌ “data is available in this repository”（误导）
* ❌ “partial datasets are included”（不清晰）
* ❌ 不解释为什么没有 full data

---

## ⭐ 如果你想再上一个档次（可选）

可以在 README 顶部加一句：

```markdown
This repository is designed to fully reproduce the results of the associated paper.
```

你现在会形成一个非常标准、审稿人喜欢的组合：

* GitHub 里：
