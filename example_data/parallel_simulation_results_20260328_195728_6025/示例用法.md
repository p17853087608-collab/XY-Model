# 1. 数据模拟
    1.运行该 数据模拟和生成\test.py 获得数据
    test.py 中可以修改参数，生成不同类型的数据
    多个并行任务需要启动多个test.py文件 来生成原始数据
    2. 在数据文件夹下运行 数据集预处理\generate_spin_visualizations.py 用于生成灰度图片映射数据
    3. 数据集预处理和分析\xy_model_PhaseData_analysis.py 用于生成数据集的统计信息 并且将 多个并行任务多个文件夹内的数据 根据温度点 整理到一个文件夹内
    4. 数据集预处理和分析\classify_png_images.py 用于将 灰度图片数据 根据 温度点 分类到 多个文件夹内
    5. 3和4的区别在于 3用于分类临界区数据 4用于分类非临界区数据
    6. 对于位于非临界点附近的数据 用3分类（会自动分类准长程有序和无序）而4只会将数据移入一个文件夹内
    7. 对于生成的灰度图片数据，需要移动到dataset文件夹下的train和test文件夹中
# 2. 深度学习模型
    ## 1. 模型训练
    1.对于深度学习模型数据的加载，需要自行创建 dataset文件夹,并在文件夹下创建train和test文件夹
    2.运行 模型训练和测试\model_train.py 进行模型训练
    ## 2. 模型预测
    1.对于我已经训练好的 模型权重\16x16\best.pth 文件
    复制到 模型训练和测试 文件夹下
    2.运行predict.py
    3.会自动加载best.pth模型权重开始预测
    4.注意 predict.py和model_train脚本需要根据 具体数据路径 进行调整
# 3. 数据分析与可视化
    1.对于预测产生的数据集文件夹，运行 后续数据处理和绘图\bkt_analysis_v2 .py 可用于生成 概率曲线图，对比图，概率曲线放大图等
    2.后续数据处理和绘图\plot_validation_confusion_matrix.py 用于生成混淆矩阵图
    3.后续数据处理和绘图\PhaseData_analysis.py 用于生成 2x2的物理量图
# 4. 辅助工具
    1.对于 数据模拟生成的原始 npy数据 ，补充\analyze_susceptibility.py 可用于计算磁化率
    2.对于 模型训练和测试\model_train.py 的使用。由于随机初始化训练的缘故，一次训练往往不能得到好的结果，使用补充\auto_train.py 用于自动训练模型，会自动记录训练结果
