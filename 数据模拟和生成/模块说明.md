# 数据模拟和生成模块说明文档

## 模块简介

本模块用于XY模型数据的生成和模拟，采用Swendsen-Wang算法进行蒙特卡洛模拟，支持多核并行计算。

## 文件说明

| 文件名 | 说明 |
|--------|------|
| `xy_simulator.py` | XY模型模拟器主入口类 |
| `xy_simulator_core.py` | 核心模拟引擎，包含Swendsen-Wang算法 |
| `xy_parallel.py` | 并行处理管理器 |
| `xy_utils.py` | 工具类（内存池、三角函数表、并查集） |
| `xy_model_simulator_parallel.py` | 向后兼容的包装器 |
| `test.py` | 测试脚本 |

## 核心架构

### 1. ParallelXYModelSimulator (xy_simulator.py)

主入口类，提供简洁接口：

```python
class ParallelXYModelSimulator(ParallelSimulationManager):
    """XY模型并行模拟器类"""
    
    def __init__(self, lattice_size=16, equilibrium_steps=1000, 
                 measurement_steps=10000, interaction_constant=1.0,
                 random_seed=None, num_processes=4)
```

### 2. XYModelSimulatorCore (xy_simulator_core.py)

核心模拟引擎，实现：
- Swendsen-Wang算法
- 自旋配置演化
- 物理量测量（能量、磁化强度、磁化率、比热）

### 3. ParallelSimulationManager (xy_parallel.py)

并行管理器：
- 多进程并行模拟
- 进度监控
- 结果收集和保存

### 4. 工具类 (xy_utils.py)

- UltraSmartMemoryPool: 内存池管理
- AdvancedTrigTable: 三角函数表预计算
- OptimizedUnionFind: 优化的并查集

## 使用方法

### 基本用法

```python
from xy_simulator import ParallelXYModelSimulator

# 初始化模拟器
simulator = ParallelXYModelSimulator(
    lattice_size=32,           # 晶格尺寸
    equilibrium_steps=1000,    # 平衡步数
    measurement_steps=10000,   # 测量步数
    interaction_constant=1.0,  # 相互作用常数J
    random_seed=42,            # 随机种子
    num_processes=4           # 并行进程数
)

# 运行模拟
results = simulator.run_simulation(
    temperature_range=(0.1, 2.5),  # 温度范围
    num_temperatures=20           # 温度点数
)
```

### 直接运行脚本

```bash
cd 数据模拟和生成
python xy_simulator.py
```

## 参数说明

### 初始化参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `lattice_size` | int | 16 | 晶格尺寸LxL |
| `equilibrium_steps` | int | 1000 | 平衡阶段蒙特卡洛步数 |
| `measurement_steps` | int | 10000 | 测量阶段蒙特卡洛步数 |
| `interaction_constant` | float | 1.0 | 交换相互作用常数J |
| `random_seed` | int | None | 随机种子（可复现结果） |
| `num_processes` | int | 4 | 并行进程数 |

### 运行参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `temperature_range` | tuple | (0.1, 2.5) | (最低温度, 最高温度) |
| `num_temperatures` | int | 10 | 温度采样点数 |

## 输出数据格式

### NPY文件

自旋配置数据：
- 形状：(L, L)
- 数据类型：float32
- 值域：[0, 2π]（弧度，表示自旋角度）

### TXT文件

物理量数据，每行格式：`温度 值`

### PNG文件

自旋构型灰度图：
- 尺寸：6x6英寸
- DPI：150
- 无边框、无标题、无颜色条

## 注意事项

1. **自动选择模式**：
   - 温度点≥4且进程数>1时自动启用并行模式
   - 否则使用串行模式

2. **内存需求**：
   - L=32: 约100MB
   - L=64: 约400MB
   - L=128: 约1.6GB

3. **计算时间**（参考）：
   - L=32, 20温度点, 4进程: 10-30分钟
   - L=64, 20温度点, 4进程: 1-3小时

4. **并行进程数**：
   - 建议不超过CPU核心数
   - 内存不足时可减少进程数

5. **数据格式**：
   - 自旋角度使用弧度制
   - 范围自动归一化到[0, 2π]

6. **文件命名**：
   - 文件夹名包含时间戳和随机数，避免冲突
