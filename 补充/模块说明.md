# 补充模块说明文档

## 模块简介

本模块包含辅助工具脚本，用于自动化训练和磁化率统计分析。

## 文件说明

| 文件名 | 说明 |
|--------|------|
| `auto_train.py` | 自动化训练脚本 |
| `analyze_susceptibility.py` | 磁化率统计分析 |

## 1. auto_train.py

### 功能说明

自动化训练循环，自动运行训练和预测脚本，判断50%概率点是否达标。

### 工作流程

```
开始
  ↓
运行训练 (model_train.py)
  ↓
运行预测 (predict.py)
  ↓
分析50%概率点温度
  ↓
是否在目标范围内？
  ├─ 是 → 保存模型，结束
  └─ 否 → 继续下一次训练
```

### 调用的脚本

```python
subprocess.run([sys.executable, 'model_train.py'])
subprocess.run([sys.executable, 'predict.py', '--no-tta'])
```

**注意**：脚本调用`model_train.py`和`predict.py`，确保这些文件存在。

### 输出文件

```
auto_train_history.csv           # 训练历史
best_model_final.pth              # 最终模型
training_summary.txt              # 训练摘要
```

### 使用方法

```bash
cd 补充
python auto_train.py
```

### 注意事项

1. **脚本依赖**：需要`model_train.py`和`predict.py`在同一目录
2. **计算时间**：每次循环可能需要30-60分钟
3. **手动停止**：Ctrl+C中断，保留已完成的结果

## 2. analyze_susceptibility.py

### 功能说明

分析XY模型的磁化率随温度变化，从npy文件加载数据，计算物理量并绘图。

### 磁化率计算公式

```python
χ = (⟨M²⟩ - ⟨|M|⟩²) / (N * kT)
```

其中：
- M：磁化强度矢量
- N：总格点数 (N = L²)
- k：玻尔兹曼常数
- T：温度

### 数据加载

扫描当前目录的npy文件，支持格式：
```
spin_config_T_{温度}.npy
```
或
```
spin_config_T_{温度}_{序号}.npy
```

### 计算流程

```python
1. 扫描并加载所有npy文件
2. 计算磁化强度 M = |∑e^(iθ)|
3. 计算 M²
4. 按温度分组统计
5. Bootstrap误差估计（n_bootstrap次）
6. 计算磁化率 χ
```

### Bootstrap误差估计

```python
def bootstrap_susceptibility_error(M_norm_list, M_sq_list, 
                                   temp, N, n_bootstrap=1000, 
                                   random_seed=None):
    """
    使用bootstrap方法估计磁化率的标准差
    
    参数:
        M_norm_list: 该温度下所有样本的|M|列表
        M_sq_list: 该温度下所有样本的|M|²列表
        temp: 温度
        N: 总格点数
        n_bootstrap: bootstrap重采样次数
        random_seed: 随机种子
    
    返回:
        chi: 磁化率
        chi_std: 磁化率的标准差
    """
```

### 输出文件

```

magnetization_L32.csv               # 磁化强度数据
susceptibility_vs_temperature.png   # 磁化率曲线

```

### CSV格式

**susceptibility_L32.csv：**
```csv

```

### 图表说明

**磁化率曲线：**
- 横轴：温度
- 纵轴：磁化率χ
- 误差棒：Bootstrap标准差
- 在相变温度处出现峰值

**磁化强度曲线：**
- 横轴：温度
- 纵轴：磁化强度|M|
- 低温度接近1，高温度降至0

### 使用方法

```bash
cd 补充
python analyze_susceptibility.py
```

### 命令行参数

```bash
python analyze_susceptibility.py [选项]

选项:
  --lattice-size L     晶格尺寸（默认32）
  --input-dir DIR      输入目录（默认当前目录）
  --output-dir DIR     输出目录（默认当前目录）
  --n-bootstrap N      Bootstrap次数（默认1000）
  --no-plot            不生成图表
  --format FMT         输出格式（csv/json/txt，默认csv）
```

### 示例

```bash
# 分析64x64晶格
python analyze_susceptibility.py --lattice-size 64

# 指定输入输出目录

# 使用500次Bootstrap
python analyze_susceptibility.py --n-bootstrap 500

# 只计算不绘图
python analyze_susceptibility.py --no-plot
```

## 注意事项

### auto_train.py

1. **脚本路径**：确保`model_train.py`和`predict_clean.py`存在
2. **工作目录**：在`模型训练和测试/`目录下运行

1. **文件命名**：必须包含`T_{温度}`格式
2. **数据格式**：npy文件形状(L,L)或(N,L,L)

## 常见问题

**Q: auto_train.py找不到脚本？**
A: 检查当前目录是否为`模型训练和测试/`，确保`model_train.py`和`predict.py`文件存在。

**Q: analyze_susceptibility.py找不到npy文件？**
A: 检查文件名是否包含`T_{温度}`格式，确保在正确目录运行。

**Q: 磁化率曲线不平滑？**
A: 增加温度采样点或使用平滑算法（需自行实现）。

**Q: Bootstrap太慢？**
A: 使用`--n-bootstrap`参数减少重采样次数。

**Q: 图表中文乱码？**
A: 脚本会自动检测系统字体，如仍有问题手动设置`matplotlib.rcParams['font.sans-serif']`。

**Q: 如何处理多个尺寸？**
A: 批量运行或修改脚本循环处理：
   ```bash
   for L in 16 32 64; do
       python analyze_susceptibility.py --lattice-size $L
   done
   ```
