# 自旋配置可视化脚本使用说明

## 📋 脚本概述

提供了三个脚本来自动读取和生成自旋配置图片：

1. **`generate_spin_visualizations.py`** - 完整版，支持多种格式和子目录扫描
2. **`simple_spin_viz.py`** - 简化版，直接处理当前目录的.npy文件
3. **`clean_spin_viz.py`** - 🆕 **纯净版**，生成无任何冗杂信息的纯灰度图

---

## 🚀 使用方法

### 方法一：完整版脚本

```bash
# 处理脚本所在目录
python generate_spin_visualizations.py

# 处理指定目录
python generate_spin_visualizations.py path/to/your/folder
```

### 方法二：简化版脚本

```bash
# 进入包含自旋配置文件的目录
cd path/to/your/spin/files

# 运行脚本
python simple_spin_viz.py
```

### 方法三：纯净版脚本（🆕 推荐）

```bash
# 进入包含自旋配置文件的目录
cd path/to/your/spin/files

# 运行纯净版脚本
python clean_spin_viz.py
```

**纯净版特点：**
- ❌ 无颜色条
- ❌ 无标题
- ❌ 无边框
- ❌ 无坐标轴
- ✅ 纯净灰度图，适合学术用途

---

## 📁 支持的文件格式

| 格式 | 扩展名 | 描述 |
|------|--------|------|
| NumPy数组 | `.npy`, `.npz` | 二进制数组数据 |
| 文本文件 | `.txt`, `.dat` | ASCII格式数据 |
| JSON文件 | `.json` | 结构化数据 |

---

## 🔍 自动识别规则

脚本会自动识别包含以下关键词的文件：
- `spin`
- `config` 
- `state`
- `lattice`
- `configuration`

## 📊 输出结果

### 图片格式

#### 完整版和简化版
- **格式**: PNG
- **颜色**: 灰度图
- **尺寸**: 6×6 英寸
- **DPI**: 150
- **包含**: 颜色条、标题、边框等（完整版）/ 部分信息（简化版）

#### 🆕 纯净版
- **格式**: PNG
- **颜色**: 纯灰度图
- **尺寸**: 与数据尺寸匹配
- **DPI**: 150
- **包含**: ❌ 无任何冗杂信息，仅纯净图像

### 目录结构
```
your_folder/
├── spin_configurations/
│   ├── spin_config_T_0.100_raw.npy
│   ├── spin_config_T_0.275_raw.npy
│   └── ...
├── generated_visualizations/          ← 完整版生成的图片
│   ├── spin_vis_spin_config_T_0.100_raw.npy.png
│   ├── spin_vis_spin_config_T_0.275_raw.npy.png
│   └── visualization_report.txt
└── clean_spin_images/                 ← 🆕 纯净版生成的图片
    ├── spin_config_T_0.100_raw.png
    ├── spin_config_T_0.275_raw.png
    └── ...
```

## 📈 灰度图说明

- **黑色** (0): 自旋角度 = 0 弧度
- **灰色** (0.5): 自旋角度 = π 弧度  
- **白色** (1): 自旋角度 = 2π 弧度

每个像素的灰度值 = 自旋角度 / 2π

## 🛠️ 高级功能

### 1. 递归扫描
完整版脚本会递归扫描所有子目录，自动找到包含自旋配置的文件夹。

### 2. 错误恢复
- 单个文件处理失败不影响其他文件
- 自动跳过不支持的格式
- 详细的错误报告

### 3. 批量处理
可以一次性处理多个文件夹，每个文件夹独立生成图片。

## 🐛 常见问题

### Q: 脚本找不到我的自旋配置文件？
A: 检查文件名是否包含识别关键词，或确保文件扩展名在支持列表中。

### Q: 生成的图片是全黑的？
A: 可能是自旋数据范围问题，脚本会自动尝试不同的归一化方式。

### Q: 内存不足错误？
A: 简化版脚本内存占用更低，或者分批处理文件。
