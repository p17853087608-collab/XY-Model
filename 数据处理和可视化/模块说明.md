# 数据处理和可视化模块说明文档

## 模块简介

本模块用于XY模型数据的处理、分类和可视化。

## 文件说明

| 文件名 | 说明 |
|--------|------|
| `xy_model_PhaseData_analysis.py` | 相变数据分析，按温度创建test文件夹 |
| `generate_spin_visualizations.py` | 从npy数据生成PNG可视化图片 |
| `classify_png_images.py` | PNG图像分类整理 |

## 1. xy_model_PhaseData_analysis.py

### 功能说明

扫描模拟结果，按温度分类PNG图像到test文件夹。

### 工作流程

```python
1. 扫描PNG文件（支持新旧两种目录结构）
2. 提取温度值（从文件名匹配 t_{温度}）
3. 创建test/T_{温度}/文件夹
4. 复制PNG文件到对应文件夹
5. 生成统计信息和图表
```

### 支持的目录结构

**新版本（并行模拟器）：**
```
parallel_simulation_results_*/spin_configurations/generated_visualizations/*.png
```

**旧版本（单进程）：**
```
simulation_results_*/spin_configurations/generated_visualizations/*.png
```

### 输出结构

```
test/
├── T_0.10/
│   ├── image_001.png
│   └── ...
├── T_0.20/
└── ...
```

### 温度提取规则

从文件名提取温度：
```python
match = re.search(r't_(\d+\.\d+)', filename)
```
匹配的文件名格式：
- `spin_vis_spin_config_t_0.750_raw.npy.png` → 温度=0.750
- `spin_config_t_3.900.png` → 温度=3.900
- `unknown_3.900_spin_config_t_3.900.png` → 温度=3.900

### 使用方法

```bash
cd 数据处理和可视化
python xy_model_PhaseData_analysis.py
```

### 注意事项

1. **PNG命名**：必须包含`t_{温度}`格式
2. **文件覆盖**：重复运行会覆盖test文件夹
3. **扫描范围**：扫描当前目录及子目录

## 2. generate_spin_visualizations.py

### 功能说明

从npy格式的自旋配置数据生成PNG灰度图，支持并行处理。

### 输入数据格式

**支持的文件格式：** .npz, .npy, .txt, .dat, .json

**数据结构：**
- 形状：(L, L) 二维数组
- 数据类型：float32或float64
- 值域：自旋角度（弧度，范围0-2π）

### 处理流程

```python
1. 读取npy文件获取自旋角度数组
2. 自动转换度数为弧度（如果max > 2π）
3. 归一化到[0, 2π]范围
4. 转换为灰度值（角度 / 2π）
5. 生成6x6英寸，150 DPI的纯净灰度图
6. 无边框、无标题、无颜色条
```

### 可视化效果

```python
grayscale = spin_array / (2 * np.pi)  # 映射到[0,1]
ax.imshow(grayscale, origin='lower', cmap='gray', vmin=0, vmax=1)
```

### 并行处理

默认使用多进程并行：
```python
max_workers = min(cpu_count(), 8)  # 最多8个进程
```

### 使用方法

```bash
cd 数据处理和可视化
python generate_spin_visualizations.py
```

### 输出

生成的PNG文件与npy文件在同一目录，文件名：
```
spin_vis_{原文件名}.png
```

### 注意事项

1. **并行模式**：支持`enable_parallel`开关
2. **DPI设置**：150 DPI，适合训练使用
3. **内存问题**：大尺寸图像可能需要减少进程数
4. **数据检查**：自动处理度数和弧度两种格式

## 3. classify_png_images.py

### 功能说明

根据温度值将PNG图片分类到"Ordered phase"或"Amorphous phase"文件夹。

### 相类型判断规则

```python
temperature > 1.0:  Amorphous phase (无序相)
temperature ≤ 1.0:  Ordered phase (有序相)
```

### 文件命名提取

**温度提取：**
```python
match = re.search(r't_(\d+\.\d+)', filename)
```

**随机数提取：**
从路径`.../parallel_simulation_results_YYYYMMDD_HHMMSS_XXXX/...`提取XXXX

### 新文件命名格式

```
{随机数}_{温度:.3f}_{核心名称}.png
```

示例：`1234_0.890_config.png`

### 输出结构

```
classified_images/
├── Ordered phase/
│   └── 1234_0.890_config.png
└── Amorphous phase/
    └── 1234_1.200_config.png
```

### 使用方法

```bash
cd 数据处理和可视化
python classify_png_images.py
```

### 输出统计

```
处理完成!
成功处理: 1000 个文件
失败: 0 个文件

相分布统计:
  Amorphous phase: 500 个文件
  Ordered phase: 500 个文件
```

### 注意事项

1. **文件复制**：复制而非移动，保留原文件
2. **温度阈值**：1.0为相变临界温度（可根据需要修改）
3. **扫描范围**：递归扫描当前目录下所有PNG文件

## 通用注意事项

1. **路径处理**：所有脚本使用`os.path.join()`处理跨平台路径
2. **错误处理**：包含try-except捕获异常
3. **进度显示**：大文件处理显示进度
4. **文件权限**：确保有读写权限
5. **磁盘空间**：PNG占用空间较大，注意磁盘容量
