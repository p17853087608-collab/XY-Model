# 模型训练和测试模块说明文档

## 模块简介

本模块用于深度学习模型的训练和预测，使用ResNet架构对XY模型自旋构型进行分类。

## 文件说明

| 文件名 | 说明 |
|--------|------|
| `model.py` | ResNet模型定义（ResNet1和Residual类） |
| `model_train.py` | 模型训练脚本 |
| `predict.py` | 预测脚本 |
| `plot_probability.py` | 概率曲线绘制 |

## 模型架构

### ResNet1模型

```python
class ResNet1(nn.Module):
    """标准ResNet模型"""
    def __init__(self, block, num_classes=10, in_channels=1):
        super(ResNet1, self).__init__()
        self.initial = nn.Sequential(
            nn.Conv2d(in_channels=1, out_channels=64, kernel_size=7, stride=2, padding=3),
            nn.BatchNorm2d(64),
            nn.ReLU(inplace=True),
            nn.MaxPool2d(kernel_size=3, stride=2, padding=1)
        )
        self.layer1 = nn.Sequential(
            block(input_channels=64, num_channels=64, use_1x1conv=False, strides=1),
            block(input_channels=64, num_channels=64, use_1x1conv=False, strides=1)
        )
        # ... 更多层
        self.fc = nn.Linear(256, num_classes)
```

### Residual残差块

```python
class Residual(nn.Module):
    def __init__(self, input_channels, num_channels, use_1x1conv=False, strides=1):
        super(Residual, self).__init__()
        self.conv1 = nn.Conv2d(in_channels=input_channels, out_channels=num_channels, 
                                kernel_size=3, stride=strides, padding=1)
        self.conv2 = nn.Conv2d(in_channels=num_channels, out_channels=num_channels, 
                                kernel_size=3, padding=1)
        self.bn1 = nn.BatchNorm2d(num_channels)
        self.bn2 = nn.BatchNorm2d(num_channels)
        if use_1x1conv:
            self.conv3 = nn.Conv2d(in_channels=input_channels, out_channels=num_channels, 
                                    kernel_size=1, stride=strides)
```

## 使用方法

### 1. 模型训练

```bash
cd 模型训练和测试
python model_train.py
```

**训练流程：**
- 加载数据集
- 自适应数据增强
- ResNet模型训练
- 验证和保存最佳模型

### 2. 模型预测

```bash
cd 模型训练和测试
python predict.py --base_path ../数据处理和可视化/test/ --output save_data/
```

**参数说明：**
- `--base_path`: 测试数据路径（默认`16x16_data_set\test`）
- `--output`: 输出文件夹（默认`save_data`）
- `--no-tta`: 禁用测试时数据增强（TTA）

**预测流程：**
- 加载默认模型（best.pth）
- 支持TTA（测试时增强）
- 批量预测
- 输出概率结果到overall_summary.csv

### 3. 绘制概率曲线

```bash
cd 模型训练和测试
python plot_probability.py
```

**输出：**
- `probability_analysis.png`
- `probability_analysis.pdf`
- 关键转折点分析

## plot_probability.py 功能

### 读取数据

从`save_data/overall_summary.csv`读取预测结果，包含：
- `folder_name`: 文件夹名称（温度值）
- `avg_ordered_probability`: 有序相平均概率
- `avg_amorphous_probability`: 无序相平均概率

### 绘制内容

- 有序相概率曲线（蓝色圆点）
- 无序相概率曲线（红色方块）
- 网格线
- 图例

### 分析输出

- 概率交叉点（差异<0.1的点）
- 极值点（最高概率的温度）
- 分段趋势分析（前后半段平均概率）

## 数据增强策略

训练使用自适应数据增强：

```python
def get_adaptive_transforms(epoch, total_epochs):
    """根据训练进度自适应调整增强强度"""
    strength = max(0.1, 1.0 - epoch / total_epochs)
    
    train_transform = transforms.Compose([
        transforms.Grayscale(num_output_channels=1),
        transforms.Resize((224, 224)),
        transforms.RandomHorizontalFlip(p=0.5),
        transforms.RandomVerticalFlip(p=0.5),
        transforms.RandomRotation(degrees=int(30*strength)),
        transforms.RandomAffine(
            degrees=0,
            translate=(0.05*strength, 0.05*strength),
            scale=(1-0.05*strength, 1+0.05*strength),
            shear=int(3*strength)
        ),
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.5], std=[0.5]),
    ])
```

## 注意事项

1. **图像格式**：
   - 输入图像自动转换为灰度图
   - 尺寸调整为224x224
   - 支持PNG、JPG格式

2. **模型加载**：
   - predict.py自动检测CUDA环境
   - GPU环境直接加载，CPU环境映射到CPU

3. **TTA增强**：
   - predict.py支持测试时增强（TTA）
   - 包含原始图像、水平翻转、垂直翻转、旋转±15度
   - 可以通过`--no-tta`禁用以加速

4. **数据路径**：
   - 使用`get_data_path()`函数处理跨平台路径

5. **中文支持**：
   - plot_probability.py设置中文字体支持

## 常见问题

**Q: 训练失败怎么办？**
A: 检查数据路径是否正确，确保文件夹名符合ImageFolder格式要求。

**Q: predict.py找不到模型？**
A: 确保当前目录有`best.pth`文件，脚本默认加载此模型。

**Q: 概率曲线中文乱码？**
A: 脚本已设置SimHei字体，如仍有问题手动设置字体。

**Q: 如何修改输入尺寸？**
A: 在model_train.py中修改transforms.Resize参数。
