# 数据归一和极限外推模块说明文档

## 模块简介

本模块用于BKT相变温度的尺度分析和极限外推，通过有限尺寸标度分析预测无限系统的相变温度。

## 文件说明

| 文件名 | 说明 |
|--------|------|
| `bkt_main.py` | BKT分析主流程 |
| `bkt_core.py` | 核心函数（数据加载、Bootstrap、BKT拟合） |
| `bkt_plotting.py` | 图表生成函数 |
| `bkt_analysis.py` | 简化版BKT分析 |
| `plot_magnetization_comparison.py` | 磁化强度对比 |

- `folder_name`: 文件夹名称（温度值）

支持的温度范围：约0.8 - 1.3 K

## 主流程 (bkt_main.py)

```python
1. 加载所有尺寸的数据
2. 对每个温度点执行Bootstrap分析（1000次）
3. 计算平均概率和标准差
4. 查找各尺寸的50%概率温度点Tc
5. BKT尺度拟合：Tc(L) = Tc(∞) + A/(ln L)^2
6. 外推至无限系统
7. 生成5张分析图表
```

## 注意事项

1. **数据路径**：
   - 必须修改`DATA_BASE_PATH`为实际路径
   - CSV文件必须存在且格式正确

2. **尺寸顺序**：
   ```python
   SIZE_ORDER = ['16', '32', '64', '128', '256']
   ```

3. **Bootstrap时间**：
   - 5个尺寸 × 1000次重采样可能需要数小时
   - 可减少`N_BOOTSTRAP`加速

4. **拟合范围**：
   - 确保温度点覆盖相变区域
   - 建议至少20个温度点

5. **图表样式**：
   - 使用Times New Roman字体
   - 适合MLST期刊风格

## 常见问题

**Q: 找不到数据文件？**
A: 检查`DATA_BASE_PATH`路径是否正确，确保CSV文件存在。

**Q: 拟合失败？**
A: 确保有足够的尺寸数据（至少3个尺寸），温度范围覆盖相变区。

**Q: Bootstrap太慢？**
A: 减少`N_BOOTSTRAP`参数值。

**Q: 如何添加新尺寸？**
A: 在`data_info`字典中添加新条目，并更新`SIZE_ORDER`。

**Q: 图表中文乱码？**
A: 脚本使用英文标注，如需中文需配置中文字体。

## BKT理论参考

有限尺寸标度公式：
```
Tc(L) = Tc(∞) + A / (ln L)^2
```

其中：
- Tc(L)：尺寸为L的系统的相变温度
- Tc(∞)：无限系统的相变温度
- A：普适常数
- L：系统尺寸
