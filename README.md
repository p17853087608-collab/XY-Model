# 基于Swendsen-Wang聚类算法的XY模型的蒙特卡洛模拟

## 介绍
XY模型模拟器是一个使用Swendsen-Wang聚类算法模拟二维XY模型的Python工具包。本模拟器支持CPU和GPU加速计算，能够高效计算不同温度下的物理量，如能量、磁化强度、比热和磁化率等。

## 使用指南
`xy_model_simulator` 文件夹是XY模型模拟器，包括模型、并行批量脚本、测试脚本和使用文档。

`idea` 文件夹是我的灵感来源。

`environment.yml` 是我的工作环境配置。在另一台机器上，使用该YAML文件可以重新创建出完全相同的环境。  
核心命令 (恢复):  
```bash
conda env create -f environment.yml
```

`simulation_results_xxxx` 文件夹保存了我的测试结果。

## 小结
现在这个模型可以非常自由地调控。

### 现在主要整成三个东西：
1. 模型脚本
2. 批处理脚本
3. 绘图脚本

### 我可以做到什么：
1. **模拟**：可以调控温度范围、蒙特卡洛步数、晶格大小、随机种子。
2. **数据分析**：有模拟过程中，每个温度点对应的物理量，以及模拟时间、模拟基本配置信息，都得到了保存。
3. **数据归类保存**：文件夹名和文件名包含各种信息。
4. **数据可视化**：可以根据温度点生成对应的RGB色彩特征图。可以根据数据分析生成温度与物理量关系图。
5. **并行计算，批量生成**：我对这个东西的专业知识一点不懂，但是这个模型可以做到多线程并行不同晶格大小和不同测量步数的模拟。
6. **模块化设计**：脚本不仅封装成类，而且有详细的操作文档，另外我正在将各个功能剥离，绘图功能我就单独剥离出来了。

### 缺点和不足：
1. 对于一种晶格大小下的大量温度点RGB色彩特征图生成，依然是串行计算，硬件利用率低，耗时长。
2. 个人电脑算力不够，无法支撑大批量数据快速生成，蒙特卡洛步数被限制，物理量测量不准确。
3.对于优化代码性能这件事我做不到，另外在进行批量计算的时候会生成一个空文件夹，我也不想管了
4. 对于RGB色彩特征图的原始信息图，没有保留。

### 打算改进的地方：
1. 打算将脚本功能的功能组合剥离，实现脚本功能单一化，便于代码调试。
2. 想办法提高代码运行的计算效率。
3. 增加保存自旋原始信息图的功能。
4. 优化代码运行时，终端的打印信息，去繁从简。
5. 优化代码，去掉冗杂代码，去掉不必要的功能。
6. 操作文档重构，去繁从简。
